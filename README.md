# Purnima’s Pharmacy

A responsive, single-page product showcase built with semantic HTML, CSS, and plain JavaScript. It uses the supplied pharmacy branding and product imagery; it has no build step or third-party runtime dependencies.

## Run locally

From this directory, start Python’s built-in static server:

```powershell
py -m http.server 4173 --bind 127.0.0.1
```

Then open <http://localhost:4173>.

## What is included

- Responsive navigation, a featured product section, category filters, product detail dialogs, and expandable answers.
- Keyboard-operable controls, visible focus styles, reduced-motion support, and descriptive image text.
- Optimised WebP derivatives in `assets/site/`; the originals in `assets/` remain untouched.

## Content and service limits

The supplied materials identify three Advancis Activon products: Manuka Honey Barrier Cream (25 g), Activon Tube (25 g), and Activon Tulle. The page does not show prices, live stock, ordering, or a pharmacy address/contact method because those details and services were not included in the project materials. Product text is limited to identification; visitors are directed to a pharmacist for personal guidance.
